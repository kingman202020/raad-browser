# متصفح رعد (Raad Browser)

متصفح ويب أندرويد سريع وآمن مبني بـ **Kotlin + Jetpack Compose**، مع **مدير تحميلات متقدم** ودعم كامل للعربية (RTL) والوضع الداكن.

## الميزات

- **واجهة عصرية شبيهة بكروم**: شريط بحث/عناوين علوي، زر تبويبات مع عداد، قائمة إعدادات منسدلة.
- **دعم كامل للعربية وRTL** (مع واجهة إنجليزية تلقائية حسب لغة الجهاز).
- **وضع داكن/فاتح**: تلقائي حسب النظام أو يدوي من الإعدادات.
- **تبويبات متعددة** مع حفظ حالة كل تبويب.
- **سجل تصفح وعلامات مرجعية** (مخزنة محلياً).
- **مدير تحميلات متقدم**:
  - نافذة قبل كل تحميل لتعديل **اسم الملف** واختيار **مجلد الحفظ** (SAF).
  - إيقاف مؤقت / استئناف (عبر HTTP Range) / إلغاء / فتح الملفات.
  - شريط تقدم لحظي وحجم الملف.
- **متوافق مع Scoped Storage**: لا يطلب أذونات تخزين في أندرويد 10+.

## البناء في Android Studio

1. ثبّت **Android Studio** (Koala أو أحدث) مع SDK 34.
2. File → Open → اختر مجلد المشروع.
3. انتظر مزامنة Gradle ثم Run (أو Build → Build APK).

## البناء من سطر الأوامر

```bash
gradle assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

## ملف APK الجاهز

يبنى تلقائياً عبر GitHub Actions عند كل push:
- من صفحة **Releases** (وسم `latest`) حمّل `app-debug.apk` مباشرة على هاتفك.
- أو من تبويب **Actions** → آخر تشغيل ناجح → Artifacts.

> ملاحظة: نسخة debug موقعة بمفتاح التصحيح، تثبّت مباشرة بعد تفعيل "التثبيت من مصادر غير معروفة".

## بنية الكود

```
app/src/main/java/com/raad/browser/
├── MainActivity.kt          # نقطة الدخول + RTL + التنقل
├── Navigator.kt             # تنقل بسيط بين الشاشات
├── Prefs.kt                 # الإعدادات (المظهر، مجلد التحميل)
├── browser/                 # المتصفح: TabManager, BrowserScreen, TabsScreen
├── downloads/               # مدير التحميلات: Engine, Dialog, Screen
├── store/                   # السجل والعلامات (JSON) + شاشاتهما
├── settings/                # شاشة الإعدادات
└── ui/                      # السمة والأيقونات والمكونات المشتركة
```
